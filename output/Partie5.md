🔹 Moment du passage Hot Storage → Cold Storage

Lorsqu’un employé quitte l’entreprise :

Pendant 12 mois, ses données restent dans la base active (Hot Storage)
→ Pour gérer les demandes RH légales (attestation, certificats, soldes de tout compte).

Après 12 mois, les données sont automatiquement déplacées vers une base d’archive sécurisée (Cold Storage) :

stockage moins coûteux, lente lecture

accès restreint (RH + Compliance)

chiffrement renforcé

données en lecture seule

 Pourquoi 12 mois ?
C’est une durée standard pour les entreprises : elle permet de respecter les contraintes administratives tout en appliquant la minimisation RGPD.

🔹 Données conservées en Cold Storage (obligations légales)

Conservation obligatoire selon la loi française :

Bulletins de paie : 5 ans

Documents comptables et fiscaux liés au salaire : 10 ans

Informations contractuelles minimales : durée légale variable

 Ces données ne peuvent pas être supprimées, même après départ.

🔹 Données supprimées définitivement (RGPD – minimisation)

Lors du passage en Cold Storage, nous supprimons :

 Données personnelles non essentielles :

Adresse email professionnelle

Numéro de sécurité sociale complet (on garde seulement une version masquée si nécessaire)

Adresse postale

Numéro de téléphone

Identifiants internes non obligatoires

Logs techniques contenant des identifiants

Données RH non requises par la loi (notes internes, entretiens, évaluations…)

 Seul ce qui est légalement requis ou justificatif administratif est conservé.

🔹 Justification RGPD

Cette politique respecte pleinement le RGPD grâce à :

Principe de minimisation : ne garder que ce qui est strictement nécessaire

Séparation Hot / Cold Storage : réduit les risques sur les données des ex-employés

Suppression irréversible des données inutiles

Accès restreint aux archives

Pseudonymisation des données conservées si possible
